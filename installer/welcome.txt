Welcome to Mawaqit Widget

This installs a small prayer-times strip above your Windows taskbar.

After setup:
  • A strip appears on the left above the taskbar
  • Left-click it to see today's prayer times
  • Right-click → "Change mosque…" to pick your mosque on a map

Requirements:
  • Windows 10 or Windows 11 (64-bit)
  • Internet connection
  • Microsoft Edge WebView2 Runtime for the in-app mosque map
    (Setup installs it if missing; the map can also open in your browser)

No programming tools are required.

Before you continue (recommended on Windows 11):
  If you downloaded this Setup from the web, right-click the
  Setup .exe → Properties → check "Unblock" → Apply.
  That avoids some SmartScreen / Application Control blocks.
